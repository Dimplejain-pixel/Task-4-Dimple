# Task-4-Dimple
AI Text Recognition System

Description

This is an AI Text Recognition System developed using Python. The project uses Optical Character Recognition (OCR) technology to extract text from images. It can identify and display text present in an image file.

Features

Loads image files
Extracts text from images
Uses OCR technology
Displays recognized text
Simple and user-friendly interface
Demonstrates basic AI and Computer Vision concepts

Technologies Used

Python
OpenCV
Pytesseract OCR

How to Run

Install Python.
Install the required libraries:

pip install pytesseract opencv-python pillow

Install Tesseract OCR on your system.
Save the project as project4.py.
Place an image file (sample.png) in the project folder.
Open Terminal or Command Prompt.
Run the following command:

python project4.py

Example

Image Contains:

HELLO DECODELABS
ARTIFICIAL INTELLIGENCE

Output:

Recognized Text:

HELLO DECODELABS
ARTIFICIAL INTELLIGENCE

Text Recognition Completed Successfully!
